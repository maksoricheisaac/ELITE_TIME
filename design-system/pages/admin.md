# Pages — Administration (utilisateurs, rôles, permissions, paramètres, LDAP, journal, e-mails) et profil

Hérite de `MASTER.md`.

- **Navigation d'administration** : sous-menu à onglets verticaux (desktop) / liste (mobile) ; page active marquée comme dans la sidebar.
- **Permissions** : arbre par domaine (pointages, congés, rapports…) avec cases à cocher, valeur par défaut du rôle indiquée, modifications en attente signalées avant enregistrement.
- **Paramètres** : sections (Horaires, Pauses, Notifications, LDAP, Messagerie) avec enregistrement par section, valeurs par défaut visibles, validation inline.
- **LDAP** : état de la dernière synchronisation (date, nombre), bouton « Synchroniser maintenant » avec état de chargement et résultat.
- **Journal d'activité** : tableau filtrable (type, utilisateur, période), heure absolue + relative, détail en panneau.
- **Profil** : identité, informations professionnelles, avatar (initiales à défaut de photo), sécurité (changement de mot de passe pour les comptes locaux, session active), préférences (thème clair/sombre/système).
- Les actions destructives demandent une confirmation nommant l'objet concerné.
